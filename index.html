About This Project

This project was developed for the MLH Global Hack Week challenge: Use GitHub Copilot to Build a Simple Application. It implements a complete dual-architecture project:

🐍

Python CLI Engine

A full terminal-based Choose-Your-Own-Adventure game with ANSI colored outputs, d20 dice checks, turn-based combat, and JSON save/load state.

🌐

Modern Web Interface

An interactive browser version equipped with real-time HUD status bars, typewriter text animation, inventory management, and responsive UI.

🤖

GitHub Copilot Driven

Demonstrates effective prompt engineering workflows using GitHub Copilot to design game loops, state machines, unit tests, and accessible interfaces.

GitHub Copilot Prompt Workflow

1

Architecture & Data Model Prompt

"Create a Python dataclass structure for a text RPG including Player (HP, Mana, Gold, Inventory), StoryNode with choices, and dynamic skill checks."
2

Branching Logic & Dice Engine

"Implement a d20 skill check system that factors in player Agility, Strength, or Intelligence and routes to success or failure story nodes."
3

Unit Testing & Verification

"Generate unittest test cases verifying node graph integrity, inventory state changes, healing bounds, and JSON save/load serialization."
